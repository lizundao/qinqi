「天伦」在关系链上对应什么？本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 泛指父子、兄弟等由出生形成的天然亲属次序，主要落在直系与同辈旁系几层。

## 关系链怎么拆

这条关系的主链是 **父**，也就是「爸爸」。在计算器里打开：[父](/calc/?chain=%E7%88%B6)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `父` | 爸爸 | 爸爸 |
| `父的父` | 爸爸的爸爸 | 爷爷 |
| `母的母` | 妈妈的妈妈 | 外婆 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 「父」「母」「子」「女」构成直系上下层。
2. 「兄、弟、姐、妹」构成同辈旁系层。
3. 「夫 / 妻」由婚姻接入，严格说属人伦而非天伦。

## 两个常见误解

- **天伦包括所有姻亲**：通常指血缘亲属的天然次序。
- **天伦等于辈分**：前者是关系类别，后者是链上层级。

亲戚称呼有明确的辈分与父系 / 母系规则，但各地习惯差异很大。本文给的是通用口径，实际称呼以自家习惯为准；需要算更长的链，用[亲戚关系计算器](/calc/)或查[常见称呼速查表](/cheatsheet/)。
