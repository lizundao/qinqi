侄子的儿子该叫什么？姐妹的孙子又为什么叫甥孙，不叫外孙？ 这篇接在「侄子与外甥：一字之差，两条链」之后——那一篇停在晚辈一层，这篇再往下跳一代；与「孙子、孙女、外孙、曾孙」对照看，就能分清直系与旁系在孙辈这一层的不同叫法。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 兄弟的孙辈在「侄 / 甥」后面加「孙」：兄的子的子实算为侄孙、兄的子之女为侄孙女、弟的子的子也是侄孙；姐妹这一支则是姐的子的子与妹的子的子，实算都叫甥孙。它与直系的孙子、外孙不同——那条链不走「兄 / 姐」这一步。

## 关系链怎么拆

这条关系的主链是 **兄的子的子**，也就是「哥哥的儿子的儿子」。在计算器里打开：[兄的子的子](/calc/?chain=%E5%85%84%E7%9A%84%E5%AD%90%E7%9A%84%E5%AD%90)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `兄的子的子` | 哥哥的儿子的儿子 | 侄孙 |
| `兄的子之女` | 哥哥的儿子的女儿 | 侄孙女 |
| `弟的子的子` | 弟弟的儿子的儿子 | 侄孙 |
| `姐的子的子` | 姐姐的儿子的儿子 | 甥孙 |
| `妹的子的子` | 妹妹的儿子的儿子 | 甥孙 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 兄弟这一支由「兄 / 弟」接入：先到侄子（兄的子 / 弟的子），再往下跳一代，「兄的子的子」与「弟的子的子」都算出侄孙，女孩则是「兄的子之女」→ 侄孙女。长幼在孙辈这一层不再换词。
2. 姐妹这一支由「姐 / 妹」接入：先到外甥（姐的子 / 妹的子），再往下跳一代，两条链实算都叫甥孙。注意它不叫「外孙」——外孙是「女的子」，走的是自己的女儿，根本不经过兄弟姐妹。
3. 这类链比直系多一个分叉：孙子走「子的子」，侄孙走「兄的子的子」，中间多了「兄」这一步，身份就从直系变旁系。链长决定辈分，接入点决定是哪一支，两者要分开看。

## 两个常见误解

- **甥孙就是外孙**：外孙是「女的子」，经由自己的女儿，属直系；甥孙是「姐的子的子 / 妹的子的子」，经由姐妹的儿子，属旁系。两条链第一步就不同，称呼也不能混。
- **侄孙和侄子差一个字，辈分一样**：侄子是「兄的子」，隔一代；侄孙是「兄的子的子」，隔两代。一字之差差整整一代，正查反查都要把链走完整。
