妻子的哥哥弟弟、姐姐妹妹，跟着妻子该怎么叫？和丈夫那边的「大伯子、小姑子」又有什么区别？ 这一篇和「大伯子、小叔子、大姑子、小姑子：丈夫的兄弟姐妹怎么称呼」是一对：那篇走「夫」，这篇走「妻」。两篇合起来，配偶的兄弟姐妹四个方向就都补齐了。表格里的大舅妇、小姨夫等是 relationship.js v1.2.9 的通用叫法，日常多以「嫂子 / 姐夫」跟着妻子叫。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 这一组全以「妻」为接入点：妻的兄叫大舅子、弟叫小舅子、姐叫大姨子、妹叫小姨子，都是同辈姻亲。它与丈夫那边的「大伯子 / 小叔子 / 大姑子 / 小姑子」完全对称——区别只在第一步走「妻」还是「夫」，两组绝不能混用。

## 关系链怎么拆

这条关系的主链是 **妻的兄**，也就是「老婆的哥哥」。在计算器里打开：[妻的兄](/calc/?chain=%E5%A6%BB%E7%9A%84%E5%85%84)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `妻的兄` | 老婆的哥哥 | 大舅子 |
| `妻的弟` | 老婆的弟弟 | 小舅子 |
| `妻的姐` | 老婆的姐姐 | 大姨子 |
| `妻的妹` | 老婆的妹妹 | 小姨子 |
| `妻的兄的妻` | 老婆的哥哥的老婆 | 大舅妇 |
| `妻的姐的夫` | 老婆的姐姐的老公 | 大姨夫 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 走「妻」这一支按长幼和性别换词：「妻的兄」算出大舅子、「妻的弟」是小舅子、「妻的姐」是大姨子、「妻的妹」是小姨子。四个称呼同在自己这一辈，差别只来自长幼和性别。
2. 和夫方那组对称着记：丈夫的兄是「夫的兄」大伯子、弟是小叔子、姐是大姑子、妹是小姑子。两组的字面完全不同，因为接入点一个是妻、一个是夫；这正是上一批「大伯子小叔子」篇的镜像。
3. 再往外还能接一跳：妻的兄的妻实算为大舅妇、妻的弟的妻是小舅妇；妻的姐的夫是大姨夫、妻的妹的夫是小姨夫。这些是配偶的兄弟姐妹的配偶，链更长一步，但仍在同辈姻亲这一层。

## 两个常见误解

- **大舅子就是舅舅**：舅舅是「母的兄」，母亲的兄弟，自己的上一辈血亲；大舅子是「妻的兄」，妻子的哥哥，与自己同辈的姻亲。链的第一步一个走「母」、一个走「妻」，辈分和血缘属性都不同。
- **大姨子就是姨妈**：姨妈是「母的姐 / 母的妹」，属母系长辈；大姨子是「妻的姐」，妻子的姐姐，属同辈姻亲。只差一个接入点，称呼的整套规则都不一样。
