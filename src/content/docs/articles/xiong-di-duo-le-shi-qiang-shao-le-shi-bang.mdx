兄弟人数多少，会改变称呼吗？本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 不会。每多一个兄弟只多一条「兄 / 弟」分支，称谓规则完全相同。

## 关系链怎么拆

这条关系的主链是 **兄**，也就是「哥哥」。在计算器里打开：[兄](/calc/?chain=%E5%85%84)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `兄` | 哥哥 | 哥哥 |
| `兄的子` | 哥哥的儿子 | 侄子 |
| `弟的子` | 弟弟的儿子 | 侄子 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 多个兄弟之间按出生先后分兄、弟，不按人数改叫法。
2. 各自的配偶、子女分支按同一规则派生。
3. 链长不因同层节点数量变化。

## 两个常见误解

- **兄弟多亲等就近**：亲等按链长，不按人数。
- **排行会改称谓**：排行只影响「大爷 / 二叔」这类口语前缀。

亲戚称呼有明确的辈分与父系 / 母系规则，但各地习惯差异很大。本文给的是通用口径，实际称呼以自家习惯为准；需要算更长的链，用[亲戚关系计算器](/calc/)或查[常见称呼速查表](/cheatsheet/)。
