什么样才算同宗？本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 共有一位父系祖先即同宗；链上表现为多条「父…父的兄 / 弟」分支汇到同一祖先。

## 关系链怎么拆

这条关系的主链是 **父的父的兄**，也就是「爸爸的爸爸的哥哥」。在计算器里打开：[父的父的兄](/calc/?chain=%E7%88%B6%E7%9A%84%E7%88%B6%E7%9A%84%E5%85%84)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `父的父的兄` | 爸爸的爸爸的哥哥 | 伯公 |
| `父的兄的子` | 爸爸的哥哥的儿子 | 堂哥 / 堂弟 |
| `父的父的父` | 爸爸的爸爸的爸爸 | 曾祖父 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 「父的父的兄」是祖父的兄长，其后代与本支共曾祖或更高祖先。
2. 同姓是线索而非证明，判定要看共同祖先。
3. 五服、族谱、祠堂位次都是传统上标记同宗距离的工具。

## 两个常见误解

- **同姓即同宗**：姓源不同、赐姓改姓都会打破这一对应。
- **同宗都是近亲**：分支越远，亲等越疏。
