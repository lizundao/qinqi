「堂哥」「表哥」听起来都是「兄弟姊妹」，但 **血缘路径不同**，在传统称谓里不能混用。

## 一句话区分

| 类型 | 核心规则 | 常见例子 |
| --- | --- | --- |
| **堂** | 父亲这边的同姓旁系（通常） | 爸爸的兄弟的子女 → 堂哥、堂妹 |
| **表** | 姑、舅、姨等姻亲/异姓旁系 | 妈妈的兄弟的子女 → 表哥、表妹 |

## 堂亲：同宗同姓一侧

「堂」多指 **同一父系家族** 内的旁系血亲。  
典型关系链：**父亲的兄弟的子女**。

- 父亲的哥哥的儿子 → 堂哥 / 堂弟（看年龄）
- 父亲的弟弟的女儿 → 堂姐 / 堂妹

## 表亲：姑舅姨一侧

「表」多指出 **父亲姐妹、母亲兄弟姊妹** 这一线的旁系。

- 妈妈的哥哥的儿子 → 表哥 / 表弟
- 爸爸的姐姐的女儿 → 表姐 / 表妹
- 妈妈的姐姐的女儿 → 表姐 / 表妹

## 为什么容易搞混

1. **日常口语** 有时把 distant 亲戚统称「亲戚哥姐」  
2. **地域叫法** 差异大，北方、粤语、闽南用词不完全一致  
3. **同辈年龄** 影响叫「哥/弟/姐/妹」，计算器可能给出多个结果

## 用计算器验证

打开 [亲戚关系计算器](/calc/)，试试：

```
爸爸的哥哥的儿子
妈妈的哥哥的儿子
```

对比结果，就能直观看到 **堂** 与 **表** 在算法里的不同路径。

## 小结

- **堂** ≈ 父亲一系、同宗旁系  
- **表** ≈ 姑舅姨等线路的旁系  
- 精确称呼还受 **性别、长幼、地域模式** 影响
