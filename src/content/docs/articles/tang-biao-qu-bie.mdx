堂兄弟姐妹和表兄弟姐妹，到底差在哪？本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 父亲的兄弟的孩子是堂亲（「父的兄的子」），其余平辈亲戚多是表亲（如「母的兄的子」）。

## 关系链怎么拆

这条关系的主链是 **父的兄的子**，也就是「爸爸的哥哥的儿子」。在计算器里打开：[父的兄的子](/calc/?chain=%E7%88%B6%E7%9A%84%E5%85%84%E7%9A%84%E5%AD%90)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `父的兄的子` | 爸爸的哥哥的儿子 | 堂哥 / 堂弟 |
| `父的兄` | 爸爸的哥哥 | 伯父 |
| `父的弟` | 爸爸的弟弟 | 叔叔 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 堂亲经「父的兄 / 父的弟」，表亲经「父的姐 / 父的妹」或母亲的兄弟姐妹。
2. 共同祖辈不同：堂亲共祖父，表亲多共外祖父或经女性旁系。
3. 传统上堂亲被视为同宗，表亲属外亲；现代法律禁止三代以内旁系血亲通婚，两者无差别。

## 两个常见误解

- **同姓就是堂亲**：关键看是否经父亲的兄弟，姓氏只是常见伴随特征。
- **表亲一定更疏**：堂表是称谓分支，不等于感情亲疏。
