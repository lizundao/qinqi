为什么老话认为表亲走动容易断？本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 表亲要经过父辈旁系再到同辈，比直系多一跳；连接点（姑、舅）不在后，往来常随之减少。

## 关系链怎么拆

这条关系的主链是 **母的兄的子**，也就是「妈妈的哥哥的儿子」。在计算器里打开：[母的兄的子](/calc/?chain=%E6%AF%8D%E7%9A%84%E5%85%84%E7%9A%84%E5%AD%90)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `母的兄的子` | 妈妈的哥哥的儿子 | 舅表哥 / 舅表弟 |
| `父的父` | 爸爸的爸爸 | 爷爷 |
| `母的母` | 妈妈的妈妈 | 外婆 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 「母的兄」是舅舅，「母的兄的子」是表兄弟，链长两跳。
2. 「父的姐的子」同样是表亲，只是走父系姐妹这一支。
3. 链上的中间长辈去世后，同辈之间缺少共同场合，走动频率下降。

## 两个常见误解

- **表亲断了就不算亲戚**：链仍在，改的是往来。
- **老表只指表兄弟**：民间「老表」也用作同乡泛称，不全是亲属。
