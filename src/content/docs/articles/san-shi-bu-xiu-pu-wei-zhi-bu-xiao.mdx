族谱里记的，和计算器算的是同一套关系吗？本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 大体同源：族谱按父系直系与旁系分支逐代记录，正是「父 / 子 / 兄 / 弟」不断展开的树。

## 关系链怎么拆

这条关系的主链是 **父的父**，也就是「爸爸的爸爸」。在计算器里打开：[父的父](/calc/?chain=%E7%88%B6%E7%9A%84%E7%88%B6)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `父的父` | 爸爸的爸爸 | 爷爷 |
| `父的父的兄` | 爸爸的爸爸的哥哥 | 伯公 |
| `父的兄的子` | 爸爸的哥哥的儿子 | 堂哥 / 堂弟 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 「父的父」是祖父，「父的父的父」是曾祖父，构成直系主干。
2. 「父的兄」「父的弟」分出房支，族谱按房支排列。
3. 旧谱多只记男系与配偶，女儿及其后代常被省略，属于记录习惯。

## 两个常见误解

- **族谱能算出所有称呼**：只覆盖被记录的人与支系。
- **没入谱就不是亲属**：谱牒是记录，不是亲属关系的成立条件。

亲戚称呼有明确的辈分与父系 / 母系规则，但各地习惯差异很大。本文给的是通用口径，实际称呼以自家习惯为准；需要算更长的链，用[亲戚关系计算器](/calc/)或查[常见称呼速查表](/cheatsheet/)。
