哥哥的女儿叫侄女，姐姐的女儿叫外甥女——一字之差，差在哪条链上？侄女和外甥女的图像为什么不一样？ 这篇补上「侄子与外甥：一字之差，两条链」没讲的女性一侧；再往下跳一代就是「侄孙、甥孙、侄孙女：兄弟的孙辈怎么称呼」，两篇对照看，父系母系的分叉规律一致。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 女性晚辈按接入的兄弟姐妹分：兄的女、弟的女都实算为侄女，走父系这一支；姐的女、妹的女都实算为外甥女，走母系这一支。区分点在第一步走的是「兄 / 弟」还是「姐 / 妹」，与本人性别无关。

## 三个要点

1. 兄弟这一支走「兄 / 弟」：兄的女、弟的女在计算器里都算出侄女；再往下跳一代，兄的子之女是侄孙女。长幼在这一层不换词，侄女就是侄女。
2. 姐妹这一支走「姐 / 妹」：姐的女、妹的女都算出外甥女。注意外甥女带「外」，和她兄弟那一侧的侄女不同——一个是姐妹的女儿，一个是兄弟的女儿。
3. 本人是谁不影响称呼：无论你男女，兄弟的女儿都是侄女、姐妹的女儿都是外甥女。称呼取决于链上「兄 / 弟」还是「姐 / 妹」这一步，不取决于你自己的性别——这是旁系晚辈最容易被直觉带偏的地方。

## 两个常见误解

- **外甥女就是侄女**：侄女走「兄 / 弟」，是兄弟的女儿；外甥女走「姐 / 妹」，是姐妹的女儿。第一步不同，一个父系一个母系，称呼不能混。
- **侄女是我叫对方的，姑姑是对方叫我的**：正查「兄的女」得到侄女，这是你称呼对方；反查「侄女称呼我」，对方才叫你姑姑或阿姨。一正一反两条链，别把两个方向的称呼叠在一起。
