爸爸的兄弟叫伯父叔父、姐妹叫姑母，那妈妈那边的兄弟和姐妹，为什么叫舅舅、姨妈？两边的孩子又为什么一个叫堂、一个叫表？ 这一篇和「伯父、叔父、姑母」正好是一对：那一篇走「父」，这一篇走「母」。两篇合起来，上一辈的八个方向（父系四、母系四）就都对齐了；再往下就是堂亲与表亲的区别，可以接着看「堂亲与表亲：关系链上怎么分」。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 母系这一支的称呼分两层：妈妈的兄弟实算为舅（大舅、小舅），姐妹为姨（大姨、小姨）；他们的孩子与自己同辈但不同宗，实算带「舅表」「姨」字样，日常统称表哥表姐表弟表妹。父系走「伯叔姑」，母系走「舅姨」，分叉点在第一步走「父」还是「母」。

## 关系链怎么拆

这条关系的主链是 **母的兄**，也就是「妈妈的哥哥」。在计算器里打开：[母的兄](/calc/?chain=%E6%AF%8D%E7%9A%84%E5%85%84)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `母的兄` | 妈妈的哥哥 | 大舅 |
| `母的弟` | 妈妈的弟弟 | 小舅 |
| `母的姐` | 妈妈的姐姐 | 大姨 |
| `母的妹` | 妈妈的妹妹 | 小姨 |
| `母的兄的子` | 妈妈的哥哥的儿子 | 舅表哥 / 舅表弟 |
| `母的姐的女` | 妈妈的姐姐的女儿 | 姨姐 / 姨妹 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 母辈这一层按长幼换词：从「母」出发走一步，「母的兄」算出大舅、「母的弟」是小舅、「母的姐」是大姨、「母的妹」是小姨。四个称呼同在一辈，字面差别只来自长幼和性别，书面语里统称舅父、姨母。
2. 同辈这一层要拐两个弯：先到「母」，再到兄弟或姐妹，最后到其子女。「母的兄的子」实算是舅表哥 / 舅表弟，「母的姐的女」是姨姐 / 姨妹——后者不带「表」字，但它仍在母系旁支上，日常一律并入表亲。
3. 父系与母系是两条平行支线，别混用：父的兄是伯父、父的弟是叔父、父的姐和妹是姑母；母的兄和弟是舅、母的姐和妹是姨。同一个「上一辈的兄弟姐妹」，第一步选父还是选母，结果整组换掉。

## 两个常见误解

- **舅舅就是叔叔**：叔叔是「父的弟」，属父系血亲，同宗同姓；舅舅是「母的兄 / 母的弟」，属母系血亲，不同宗。链的第一步就分叉，后续称呼没有一个是通用的。
- **表哥和堂哥是一回事**：堂哥是「父的兄的子」，与自己同宗同姓，属父系旁支；表哥来自母系（母的兄的子）或父系姐妹这一支（父的姐的子），不同宗。日常说的「堂」「表」之分，本质是宗族归属，不是亲疏远近。
