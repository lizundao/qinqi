儿子或女儿结婚以后,男方父母和女方父母彼此该怎么称呼?为什么两边叫法一样? 这类称呼在计算器里要拆成三层「子 / 女 → 妻 / 夫 → 父 / 母」,属于跨度较大的姻亲链;地区习惯上也有直接叫「亲家」或随子女称呼对方老人的写法。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 通过子女的配偶相连:儿子的妻子之父是亲家公、之母是亲家母;女儿的丈夫之父、之母也叫亲家公、亲家母,称呼对称,不随自己性别改变。

## 关系链怎么拆

这条关系的主链是 **子的妻的父**，也就是「儿子的老婆的爸爸」。在计算器里打开：[子的妻的父](/calc/?chain=%E5%AD%90%E7%9A%84%E5%A6%BB%E7%9A%84%E7%88%B6)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `子的妻的父` | 儿子的老婆的爸爸 | 亲家公 |
| `子的妻的母` | 儿子的老婆的妈妈 | 亲家母 |
| `女的夫的父` | 女儿的老公的爸爸 | 亲家公 |
| `女的夫的母` | 女儿的老公的妈妈 | 亲家母 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 关系链从自己出发:以男方父亲为例,是「子的妻的父」——先到儿子,再到儿媳,最后接她的父亲,得到亲家公。
2. 称呼对称:无论你是男方还是女方家长,对方的父亲都是亲家公、母亲都是亲家母,不存在「公」与「母」随己方性别互换。
3. 这是纯姻亲:亲家不是血亲,是两段婚姻在子女身上交会带出来的关系,没有直接的血缘链相连。

## 两个常见误解

- **亲家是兄弟**：亲家是两家父母之间的互称,和兄弟无关;称对方孩子用儿媳、女婿,不叫侄子。
- **亲家母就是岳母**：亲家母是对方家长,岳母是自己妻子的母亲,两条链起点不同,不能等同。
