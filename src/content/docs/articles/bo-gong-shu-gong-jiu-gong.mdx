爷爷的兄弟、外公外婆的兄弟姐妹，这些隔了一辈的长辈该怎么叫？ 标题里的舅公、姨婆是各地口语简称，表格里的称呼是 relationship.js v1.2.9 实算的通用叫法（舅外公、姨外婆）；两套说法指同一条链，实际以自家习惯为准。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 先分父系母系再论长幼：祖父的兄弟实算为伯公、叔公，祖父的姐妹是姑奶奶；外祖母的兄弟是舅外公、姐妹是姨外婆，口语里常简称舅公、姨婆。父系带「公 / 奶奶」，母系带「外公 / 外婆」。

## 关系链怎么拆

这条关系的主链是 **父的父的兄**，也就是「爸爸的爸爸的哥哥」。在计算器里打开：[父的父的兄](/calc/?chain=%E7%88%B6%E7%9A%84%E7%88%B6%E7%9A%84%E5%85%84)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `父的父的兄` | 爸爸的爸爸的哥哥 | 伯公 |
| `父的父的弟` | 爸爸的爸爸的弟弟 | 叔公 |
| `母的母的兄` | 妈妈的妈妈的哥哥 | 舅外公 |
| `母的母的姐` | 妈妈的妈妈的姐姐 | 姨外婆 |
| `父的父的姐` | 爸爸的爸爸的姐姐 | 姑奶奶 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 父系这一支：从「父的父」（祖父）往外走一步，「父的父的兄」算出伯公、「父的父的弟」是叔公、「父的父的姐 / 妹」是姑奶奶；比「父的兄」（伯父）整整多一跳。
2. 母系这一支：从「母的母」（外祖母）往外走，「母的母的兄 / 弟」实算是舅外公，「母的母的姐 / 妹」是姨外婆；日常说的舅公、姨婆是它们的口语简称，计算器用的是通用叫法。
3. 后缀能看出分叉：父系长辈多带「公 / 奶奶」，母系长辈多带「外公 / 外婆」。同一个「祖辈的兄弟」，走「父的父」还是「母的母」，结果就不同，这正是关系链比印象可靠的地方。

## 两个常见误解

- **舅公就是舅舅**：舅舅是「母的兄」，母亲的兄弟；舅公（实算舅外公）是「母的母的兄」，外祖母的兄弟，多了一层，属于祖辈而非母辈。
- **伯公和伯父是一回事**：伯父是「父的兄」，伯公是「父的父的兄」；前者是爸爸的哥哥，后者是爷爷的哥哥，链长差一跳，辈分差一代。
