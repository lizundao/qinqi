舅舅和叔叔，为什么被分开说？本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 舅舅是「母的兄 / 母的弟」，走母系；叔叔是「父的弟」，走父系。

## 关系链怎么拆

这条关系的主链是 **母的兄**，也就是「妈妈的哥哥」。在计算器里打开：[母的兄](/calc/?chain=%E6%AF%8D%E7%9A%84%E5%85%84)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `母的兄` | 妈妈的哥哥 | 大舅 |
| `父的父` | 爸爸的爸爸 | 爷爷 |
| `母的母` | 妈妈的妈妈 | 外婆 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 「母的兄」算舅舅，「父的弟」算叔叔，第一字就分了系。
2. 「父的兄」是伯父，与叔叔同属父系旁系长辈。
3. 姑父、姨父、舅妈由婚姻接入，属姻亲，俗语因此说「不亲」。

## 两个常见误解

- **舅和叔是同一层不同叫法**：父系母系分叉，后续表亲 / 堂亲也不同。
- **姑父姨父没有亲属关系**：他们是姻亲，链上确有位置。
