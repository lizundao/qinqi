舅舅为什么在传统礼俗里格外有分量？本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 舅舅是「母的兄 / 母的弟」，是母系最贴近的旁系长辈，常在外甥婚丧、分家等场合担任见证角色。

## 关系链怎么拆

这条关系的主链是 **母的兄**，也就是「妈妈的哥哥」。在计算器里打开：[母的兄](/calc/?chain=%E6%AF%8D%E7%9A%84%E5%85%84)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `母的兄` | 妈妈的哥哥 | 大舅 |
| `父的父` | 爸爸的爸爸 | 爷爷 |
| `母的母` | 妈妈的妈妈 | 外婆 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 「母的兄」是舅舅，从外甥视角反查即「姐的子」或「妹的子」。
2. 舅妈是「母的兄的妻」，由婚姻接入，属姻亲。
3. 舅权是礼俗角色，不改变链的长度与亲等。

## 两个常见误解

- **舅舅比父亲更亲**：两者分属母系旁系与父系直系，不可直接比亲等。
- **舅王是官职**：民间敬称，非制度职位。
