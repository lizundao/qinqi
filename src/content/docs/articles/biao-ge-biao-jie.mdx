姑姑、舅舅、姨妈家的孩子，该怎么称呼？表哥、表姐、表弟、表妹到底怎么区分？ 一句话记：父之兄弟的子女是堂，父之姐妹与母之兄弟姐妹的子女是表；计算器把「的」节点一摆，堂表立分。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 表亲来自父系姐妹（姑表）与母系兄弟姐妹（舅表、姨表）的子女；关系链上的「的」节点决定是姑表、舅表还是姨表，而哥/姐还是弟/妹只看对方年龄。

## 关系链怎么拆

这条关系的主链是 **父的姐的子**，也就是「爸爸的姐姐的儿子」。在计算器里打开：[父的姐的子](/calc/?chain=%E7%88%B6%E7%9A%84%E5%A7%90%E7%9A%84%E5%AD%90)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `父的姐的子` | 爸爸的姐姐的儿子 | 姑表哥 / 姑表弟 |
| `母的兄的子` | 妈妈的哥哥的儿子 | 舅表哥 / 舅表弟 |
| `母的姐的女` | 妈妈的姐姐的女儿 | 姨姐 / 姨妹 |
| `父的妹的女` | 爸爸的妹妹的女儿 | 姑表姐 / 姑表妹 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 姑表来自父亲这边的姐妹：「父的姐的子」「父的妹的子」算出姑表哥 / 姑表弟，姐妹的孩子算姑表；这是父系里唯一「外嫁」出去又连回来的那一支。
2. 舅表、姨表来自母亲这边：「母的兄的子」「母的弟的子」是舅表哥 / 舅表弟（舅舅的孩子），「母的姐的女」「母的妹的女」是姨姐 / 姨妹（姨妈的孩子）；母亲兄弟姐妹的子女都算表亲。
3. 哥还是弟、姐还是妹，计算器给的是两个候选（如姑表哥 / 姑表弟），因为程序不知道对方年龄；实际叫法由谁大谁小决定，链本身不变。

## 两个常见误解

- **表哥就是堂哥**：堂亲只来自「父的兄 / 父的弟」的子女（同姓、同宗），表亲来自姑、舅、姨；堂和表在关系链第一步就分叉。
- **表亲都不算近亲**：表亲之间结构上是旁系，但「出五服」之后往来自然疏远；是否近亲要看具体链长，不能一概而论。
