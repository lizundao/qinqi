爸爸的哥哥、弟弟、姐姐、妹妹，日常到底该叫伯父、叔叔、姑妈还是别的？为什么有的地方叫大爷、大伯？ 这类称呼只用了「父、兄、弟、姐、妹」五个原语加上配偶链,是计算器最基础的一层;把长幼和配偶分开看,就不会把伯母和婶婶叫反。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 父系平辈都由「父」接一个同胞原语构成：父的兄是伯父、父的弟是叔父、父的姐与父的妹统称姑母；再各自接配偶，就得到伯母、婶婶。

## 关系链怎么拆

这条关系的主链是 **父的兄**，也就是「爸爸的哥哥」。在计算器里打开：[父的兄](/calc/?chain=%E7%88%B6%E7%9A%84%E5%85%84)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `父的兄` | 爸爸的哥哥 | 伯父 |
| `父的弟` | 爸爸的弟弟 | 叔叔 |
| `父的姐` | 爸爸的姐姐 | 大姑 |
| `父的妹` | 爸爸的妹妹 | 小姑 |
| `父的兄的妻` | 爸爸的哥哥的老婆 | 伯母 |
| `父的弟的妻` | 爸爸的弟弟的老婆 | 婶婶 |

上表的称呼由 [relationship.js](https://github.com/mumuy/relationship) v1.2.9 实际计算得出，采用通用叫法；北方、广东等地区叫法可能不同，可在[计算器](/calc/)里切换对照。

## 三个要点

1. 区分关键在长幼：父亲的哥哥无论几个都叫伯父，口语常称大爷、大伯；父亲的弟弟叫叔父、叔叔。计算器只按链上的「父 → 兄 / 弟」判断,不区分第几。
2. 父亲的姐妹统称姑母：年长的叫大姑、姑妈,年幼的叫小姑、姑姑;她们和父亲同属一个父系小家庭,是直系同胞。
3. 配偶要再算一层：父的兄的妻子是伯母,父的弟的妻子是婶婶;姑母的丈夫叫姑父,属姻亲,不在父系血亲链内。

## 两个常见误解

- **伯父就是大爷**：大爷、大伯、伯父是同一位(父亲的哥哥)的不同叫法,南北习惯不同,不算两种亲戚。
- **姑妈算父系亲戚**：姑母是父亲的姐妹,仍属父系,和母系的姨母(母亲的姐妹)不是一条链,称呼不能混。
