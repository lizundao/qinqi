儿子娶进来的、女儿嫁出去的，为什么一个叫儿媳、一个叫女婿？往上再走一步，又会碰到谁？ 口语里儿媳也叫儿媳妇、女婿也叫姑爷，都是同一条链的不同叫法。表格用的是 relationship.js v1.2.9 的通用叫法；各地习惯不同，可在计算器里切换北方 / 广东叫法对照。本文按「关系链 → 称呼」的方式拆开来讲，不谈感情，只讲怎么算、怎么叫。

## 一句话结论

> 子女这一层的配偶按接入点分：子的妻实算为儿媳、女的夫为女婿。两者都属同辈姻亲，第一步走「子」还是「女」决定用词；再往外一跳（子的妻的父、女的夫的父）都会汇到亲家公、亲家母，这正是婚礼上双方父母互称的那条链。

## 关系链怎么拆

这条关系的主链是 **子的妻**，也就是「儿子的老婆」。在计算器里打开：[子的妻](/calc/?chain=%E5%AD%90%E7%9A%84%E5%A6%BB)。

| 关系链 | 换成日常说法 | 通常叫 |
| :--- | :--- | :--- |
| `子的妻` | 儿子的老婆 | 儿媳 |
| `女的夫` | 女儿的老公 | 女婿 |
| `兄的妻` | 哥哥的老婆 | 嫂子 |
| `弟的妻` | 弟弟的老婆 | 弟妹 |
| `姐的夫` | 姐姐的老公 | 姐夫 |
| `妹的夫` | 妹妹的老公 | 妹夫 |

## 三个要点

1. 子女这一层只差一个字：从「子」接到「妻」，「子的妻」算出儿媳；从「女」接到「夫」，「女的夫」算出女婿。两边都是子女带回家的配偶，辈分与自己相同，属于婚姻这条桥接进来的姻亲。
2. 再往外一跳就到了亲家：无论从儿子那边走「子的妻的父」，还是从女儿那边走「女的夫的父」，实算都是亲家公；换成母就是亲家母。所以婚礼上两家人的互称，本质是把子女配偶那条链再往外走一步。
3. 别和兄弟姐妹的配偶混了：哥哥的妻子是嫂子、弟弟的妻子是弟妹、姐姐的丈夫是姐夫、妹妹的丈夫是妹夫——这四条也是同辈姻亲，但接在「兄 / 弟 / 姐 / 妹」上，不是接在「子 / 女」上，第一步就分叉。

## 两个常见误解

- **儿媳就是女儿**：儿媳是「子的妻」，儿子带回家的配偶，属姻亲；女儿是「女」，自己的直系血亲。一个是娶进来的，一个是自己生的，血缘属性完全不同。
- **女婿等于半个儿子，就是儿子**：这只是民间说法，链上并不成立。女婿是「女的夫」，接在女儿这一支上；儿子是「子」，自己的直系后代。「半个儿」讲的是赡养角色，不改变它是姻亲而非血亲。
